# effort-router — Qwen Code 어댑터

삽입처: `~/.qwen/QWEN.md`(글로벌) 또는 프로젝트 루트 `QWEN.md`. Qwen은 `AGENTS.md`도 판독하므로 기존 AGENTS.md 운영 중이면 병행 배치를 권장한다.

> 본 문서는 effort-router SKILL.md(§1 티어·§3 제약·§6 매핑)의 파생 축약 이식본이다 — 규칙 충돌 시 본문이 우선한다. 본문 갱신 시 본 파일도 파생 갱신한다.

## 티어 판정 (본문 §1 축약)

- **S** 단일 파일·텍스트/스타일 · **M** 2~10파일·~1000줄 이하·위험 지표 음성 · **L** 10파일·1000줄 초과 또는 위험 지표 양성(규모 무관) · **XL** 코어 엔진·전면 리팩터링 · **보안감사** 별도 트랙
- **폴백**: 지표 충돌 시 상위 티어 — 하향 예외는 실질이 국소·기계적 변경임이 확인될 때 근거와 함께만.
- **은닉 변수**(해당 시 1티어 상향): 요청 경로 동작 변경 / 보안 통제 자체 변경 / 코드만으로 판별 불가 변수(확인 질문 1개 선행).

## 실행 계약 (본문 §3·Output Contract 축약)

- 작업 착수 전 티어 판정·실행 지침 요약을 먼저 출력한다.
- 타 하니스 표기: 적용 에이전트 라인 = 아래 대응물 또는 `없음(단일 세션)`, 팬아웃 라인 = `OFF`, 단계 상태 라인은 인계를 실제 운반할 때만 기입.
- **적용 제외: §2 화이트리스트·팬아웃·state.json(§5)** — Claude Code 전용 계약이다.

## Qwen 대응 (본문 §6)

- 서브에이전트: `/fork` 배경 에이전트(전체 대화 상속) — 역할별 서브에이전트 시스템은 **미확인**.
- effort 상당 설정 키: **미확인** — settings `model.*` 네임스페이스는 존재하나 effort 직접 대응 키는 공식 문서에서 확인하지 못했다. 확인 전까지 effort 배정을 단정하지 않는다.
- 설정: `~/.qwen/settings.json`(사용자)·`.qwen/settings.json`(프로젝트, 우선) — 7레이어 우선순위.
- 대안 배치: `.qwen/skills/`에 Agent Skills(SKILL.md) 지원은 공식 확인 — 본 스킬의 판정 규칙을 SKILL.md 형태로 두는 배치도 가능하다.
- 역할 분리가 필요하면 본 스킬의 에이전트명(plan-high 등)을 지목하지 않는다 — 대응물이 확인될 때까지 단일 세션 진행을 기본으로 한다.
